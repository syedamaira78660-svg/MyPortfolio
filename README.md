# Syeda Maira Saad — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript with no build step.

- `index.html` — page content
- `css/styles.css` — styles and animations
- `js/main.js` — scroll reveals, progress bar, rotating role line, contact form
- `assets/` — images

Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).
